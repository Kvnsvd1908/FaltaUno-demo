# FaltaUno

Frontend responsive para deportistas amateur que necesitan encontrar rápidamente a un jugador para completar un partido de fútbol, básquetbol o pádel.

* Kevin Soto

## Tecnologías

* **HTML5 semántico:** Estructura organizada con etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) y atributos ARIA para accesibilidad universal.
* **CSS3:** Estilos propios, variables en `:root` con paleta institucional verde deportiva y diseño adaptable mediante `@media queries`.
* **Bootstrap 5:** Sistema de grillas responsivas de 12 columnas (`col-12 col-md-6`), utilidades Flexbox y componentes nativos (Navbar colapsable, Modal centrado, Cards, Badges y Alertas).
* **JavaScript (ES6+ Vanilla):** Datos simulados en arrays y objetos, manipulación dinámica del DOM (`innerHTML`, Template Literals), eventos (`click`, `input`, `submit`), buscador y filtros reactivos, y validación lógica de formularios con control de fechas.

## Funcionalidades

* Listado de partidos con datos simulados.
* Búsqueda por deporte, nivel o ubicación.
* Filtros por fútbol, básquetbol y pádel.
* Inscripción y cancelación de partidos con actualización del DOM.
* Formulario modal para publicar partidos, con validación visual.
* Panel de “Mis partidos” con estado confirmado.
* Diseño responsive para móvil, tablet y escritorio.

## Instrucciones

Abre `index.html` en el navegador. Bootstrap se carga desde su CDN, por lo que se necesita conexión a internet para visualizar sus estilos y componentes.
