# FaltaUno

Frontend responsive para deportistas amateur que necesitan encontrar rápidamente a un jugador para completar un partido de fútbol, básquetbol o pádel.

## Tecnologías

- HTML5 semántico
- CSS3
- Bootstrap 5
- JavaScript

## Funcionalidades

- Listado de partidos con datos simulados.
- Búsqueda por deporte, nivel o ubicación.
- Filtros por fútbol, básquetbol y pádel.
- Inscripción y cancelación de partidos con actualización del DOM.
- Formulario modal para publicar partidos, con validación visual.
- Panel de “Mis partidos” con estado confirmado.
- Diseño responsive para móvil, tablet y escritorio.

## Instrucciones

Abre `index.html` en el navegador. Bootstrap se carga desde su CDN, por lo que se necesita conexión a internet para visualizar sus estilos y componentes.
